## 📚 Sobre Aprendizado de Máquina

O **Aprendizado de Máquina (Machine Learning)** é um subcampo da Inteligência Artificial que permite que computadores aprendam padrões a partir de dados e realizem previsões ou tomadas de decisão sem serem explicitamente programados. :contentReference[oaicite:1]{index=1}

No **Aprendizado Supervisionado**, os algoritmos são treinados utilizando dados rotulados, ou seja, cada exemplo do conjunto de treinamento possui uma entrada e uma saída esperada. Esse tipo de aprendizado é amplamente utilizado em problemas de:

- Classificação
- Regressão
- Predição de valores
- Reconhecimento de padrões
